# Jeen · מחשבון תמחור למערך בתי החולים

אפליקציית ווב לתמחור פלטפורמת Jeen AI לבתי החולים של מערך בתי החולים הממשלתיים.

- **בית חולים** – עלות השנה הראשונה וכל שנה נוספת לפי נתוני השימוש.
- **כל המערך** – תרחישי הצטרפות ועלות ל-5 שנים.
- **מחירון** – מחירי יחידה ומדרגות הנחת נפח.
- **הפקת הצעת מחיר** – מסמך Word ומחשבון Excel לבית החולים, ישירות מהדפדפן.

קובץ יחיד (`index.html`) ללא שרת וללא בנייה. החישובים רצים בדפדפן, ושום מידע לא נשלח לשרת.
הרכיבים להפקת Word ו-Excel (docx, ExcelJS) נטענים מ-jsDelivr רק בעת לחיצה.

## עדכון
עורכים את `index.html` ודוחפים ל-`main`. GitHub Pages מתעדכן תוך כדקה.

## פרסום
Settings → Pages → Deploy from a branch → `main` / root.
